MAESTRO

An orchestrator for Claude Code, with a name and a character you choose. It remembers what you do.

PRESS START SOURCE CODE

Maestro is a template for Claude Code. You create an instance, give it a name and a character, and talk to it every day. It records what happens in a local memory and writes your daily logbook into your notes. Behind it, a small team of agents does the specialised work.

One instance per context, for your personal life or for your job. Instances live side by side on the same machine and talk to each other.

SESSION

~/work · claude

A made-up session. Every write to memory is announced in one line, so you can fix a title or a tag on the spot.

Memory has three layers. The log, one SQLite file, holds facts, tasks and ideas that the orchestrator writes while you talk. The vault is your folder of markdown notes. With Ollama installed, both go into one semantic index: a search by meaning returns the closest memories and note sections, each with its source.

A sub-app is a project plugged into the instance: a symlink in apps/ and a pointer skill that tells the orchestrator when the project matters. You stay in the instance's session, and the orchestrator reaches into the project with the same memory, skills and vault. Each app is read-only or read-write.

A satellite is a project repository that orbits an instance, its mother. You work in the repo as usual; the session borrows the mother's identity and gets a memory scope of its own. It asks the mother questions or hands her work in the background, and nothing is added to the repo. Instances talk to each other through maestro-net.

INVENTORY

MEMORY

A SQLite log of facts, tasks and ideas, written while you talk. Every read and write goes through bin/mem.

LOGBOOK

Say "recap of today" and the day becomes a first-person note in your vault, in your language.

AGENTS

librarian, scheduler, steward and hr. You talk to them through the orchestrator; HR hires new ones on your approval.

WRITING REGISTER

Seven prose prohibitions and your own tone, checked before an email, a post or a document goes out.

LISTEN

/listen follows a call in progress, answers questions about what was said and files the transcript at the end.

SYNC

/maestro:maestro-sync brings template updates into an instance, with a backup and a rollback.

The last step runs inside Claude Code. It interviews you about your language, the orchestrator's name and character, and where your notes live, then sets up the instance in a folder of your choice.

Requires Claude Code, git and Python 3. Optional: Ollama and uv for the semantic index. The full guide is in the README.
